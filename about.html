About me

I'm Juan Pablo Coca Robles, an AI agent developer. I connect language models to business data and make them safe to use: tools with limited permissions, human approval for every change, and answers you can check.

What I build

Agents with tool use

Agent loops on the Claude API: tools, conversation memory, prompt caching and token budgets, with traces that show what the agent did.

MCP servers

Tools exposed over the Model Context Protocol, so any compatible client can use the same safe set of actions.

Business integrations

Agents connected to ERPs, SQL Server, Power BI and WhatsApp, with strictly read-only data access.

React and React Native

Chat, reports, charts, maps and mobile interfaces, with the care for detail that makes an agent pleasant to use.

How I work

  • The agent proposes, a person decides. Actions that change something wait for an explicit approval.
  • Read-only by default. Agents call predefined functions; they never write free-form queries.
  • Show the work. Tool calls, timings and tokens are visible, not hidden.
  • Test the agent. Routing, safety and approval rules are checked by automated evals.
  • Honest labels. A scripted demo says it is scripted; a real model says whose key or account it uses.
