Virtual Assistant with an AI Agent for ERP

A chat and executive-reporting assistant built on top of an ERP for an import and distribution company. It runs as an embedded widget inside the ERP, as a standalone web app and over WhatsApp.

Node.jsTypeScriptClaude APITool useSQL ServerReactViteTailwindRechartsASP.NET CoreWhatsApp Cloud API

Built at my job. The source code and real data belong to the company, so this page describes the design only. The demo uses fictitious data ("Empresa Demo") and is rebuilt from scratch.

The problem

Managers had to ask analysts for sales, stock and receivables numbers, or dig through several screens in the ERP, a routing/CRM tool and Power BI. Answers came late and in different formats.

The solution

One assistant that answers questions in natural language, shows tables and charts, and sends scheduled reports. Each channel only sees the data it needs:

  • Widget in the ERP: ERP data only.
  • Standalone app: ERP + salesperson routing + Power BI together.
  • WhatsApp: routing and commercial data, with charts sent as images and links to reports.

My role

I designed and built it end to end: the backend, the agent loop, the Power BI microservice, the WhatsApp integration and both React frontends.

Architecture

Green = read-only data path.

Technical decisions

Strictly read-only data access

Three layers: a SQL login without write permissions, a guard in code that rejects anything that is not SELECT/WITH, and an agent that can only call predefined repository functions. It never writes free-form SQL.

Agent loop with tool use

Claude API with tool use in an agentic loop and conversation memory. The model picks a tool, the backend runs it and the result goes back until the answer is ready.

Prompt caching

The system prompt and tool definitions are cached, which lowered the cost per message.

One chat per channel

Each channel has its own tools and scope, so a user only reaches data that fits that channel.

Power BI as a service

A small ASP.NET Core microservice exposes the Power BI Desktop model over HTTP so the agent can query it like any other tool.

WhatsApp Business Cloud API

Webhook-based, with charts sent as images, links to reports and automated scheduled messages.

Cost control

AI token consumption is tracked and limited per user.

Two frontend builds

React + Vite + Tailwind + Recharts, plus maps (salesperson routes and heat maps). One build for the standalone app and another for the embeddable widget, isolated with Shadow DOM.
